# Contribute a Kling 4.0 prompt

[Home](README.md) · [Catalog](prompts/README.md)

Share a complete creative task that another person can understand, adapt, and review. New scenes, useful corrections, careful translations, and documented results are welcome.

## A useful submission

Include:

- A specific title, use case, and intended framing.
- The selected workflow and every required input.
- A complete copy-ready prompt with action, camera, sound, and ending.
- Adjustable details and an observable review target.
- Whether it is a recipe or a tested result.
- For a test: model selection, platform, settings, input roles, and a public result you may share.

Use the [prompt submission form](https://github.com/bestimageai/awesome-kling-4-0-prompts/issues/new?template=prompt.yml). A [scenario request](https://github.com/bestimageai/awesome-kling-4-0-prompts/issues/new?template=scenario.yml) can describe a missing use case without supplying a finished prompt.

## Entry format

```markdown
## Descriptive scene title

**Use:** the creative purpose. **Mode:** the workflow. **Brief:** intended duration and framing. **Inputs:** required assets and their roles.

Complete prompt in a fenced text block.

**Adjust:** meaningful variables. **Review:** visible or audible success criteria.
```

Maintainers assign a stable prompt ID when adding an entry. Keep existing IDs unchanged so links remain useful.

## Media and sources

Contribute material you created or have permission to share. State the creator, original source, applicable terms, and any edits. Keep input references distinct from generated results.

Official examples belong in the official gallery with their source links. They do not become outputs of a new recipe merely because the recipe uses a similar technique. Third-party media is not covered by this repository's MIT license.

Do not include credentials, private source material, or expiring authenticated links. Obtain permission for identifiable people and voices.

## Translation

Translate the current English entry and preserve numbers, input roles, action order, speaker ownership, and review targets. Use natural local phrasing. Do not substitute a similar scene or leave untranslated prose as filler.

The localized READMEs are entry guides with a shared example. They are not complete catalog translations.

## Focused changes

Keep a contribution limited to the scene or correction it explains. Check relative links, anchors, code fences, and counts. Preserve existing useful comments and source attribution.
