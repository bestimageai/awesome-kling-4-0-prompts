## From a useful example to your own brief

Start with the [official gallery](official-examples.md) when you want to see how a reference, edit, or keyframe is used in a real published example. Choose a related original recipe from the catalog, then replace its scene and inputs with your own.

For a product film, keep the product geometry explicit. For a portrait, decide whether expression or body movement matters most. For a story, identify the change that makes the ending different from the opening.

Use the model page for the available controls and the documentation for request fields. The creative mode labels in the catalog are not API route names.

## Make the next attempt more useful

Keep one approved version of the brief and adjust one meaningful variable at a time: camera path, action timing, dialogue, or reference choice. Compare the whole result against the entry's review target. When a scene works for your project, save the prompt and input roles together.
