# Choose a Kling 4.0 workflow

The official guide distinguishes Omni Reference from the separate Keyframes entry. Choose one workflow for a task. Reference assets define ingredients; key images establish visual moments.

| Creative need | Recipe collection | What to prepare |
|---|---|---|
| Explore a written scene | [Cinematic stories](../prompts/cinematic-stories.md) | A concise description and an observable ending |
| Animate an existing composition | [Product films](../prompts/product-films.md) | A clear first image with room for the intended action |
| Combine identity, location, or motion | [Omni Reference](../prompts/omni-reference.md) | Assets with explicitly separated roles |
| Change existing footage | [Video editing](../prompts/video-editing.md) | A source clip and a bounded change |
| Reach prepared compositions | [Keyframes](../prompts/keyframe-transitions.md) | Compatible images in narrative order |
| Direct speech and reactions | [Dialogue](../prompts/dialogue-performance.md) | Exact lines, speaker positions, and pauses |

The guide treats voice references separately from music and sound-effects direction. Describe the desired ambience in words rather than assuming an uploaded soundtrack becomes a voice reference.

## Frame preparation

For a product, make sure the defining edges are visible. For a person, use an authorized reference with a clear face and clothing. For two endpoint images, compare object count, camera height, light direction, and the physical change required between them.

The [reference recipes](../prompts/omni-reference.md) and [keyframe recipes](../prompts/keyframe-transitions.md) are kept separate so their input instructions remain easy to follow.

## Provider and platform

The [official guide](https://kling.ai/quickstart/kling-4-model-user-guide) explains Kling's own workflows. [bestimage.ai model pages](bestimage-workflow.md) provide the corresponding product entry points. Choose controls from the interface and documentation of the platform you use.

Kling 4.0 and Kling 4.0 Flash are distinct selections. Do not transfer a setting from one selection to another without checking its controls. This library focuses on creative briefs rather than a shared parameter table.

## What a sample proves

An official sample shows a result published by Kling AI. A recipe in this library expresses an intended scene. Neither guarantees the same result for a different input, setting, or model selection. Use the [review targets](troubleshooting.md) to inspect your own output.
