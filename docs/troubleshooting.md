# Review the scene, then revise the brief

[Home](../README.md) · [Catalog](../prompts/README.md) · [Prompting guide](prompting-guide.md)

Watch the result once at normal speed, then inspect the specific event the recipe asks you to review. Look at the beginning and ending as well as the most attractive frame.

| Symptom | Check | Try next |
|---|---|---|
| A face changes behind an object | Frames before and after the occlusion | Shorten the occlusion and keep the identity reference clear |
| A prop duplicates | Every entry, handoff, and exit | State a single starting object and keep the transfer visible |
| Product details drift | Seams, controls, holes, and silhouette | Simplify movement and use an unobstructed product reference |
| Hands pass through a surface | First contact and release | Reduce speed and choose a view showing the contact point |
| An object floats | Feet, base, contact shadow | Specify the supporting surface and the final resting state |
| Camera movement changes the room | Corners, doorway, floor pattern | Shorten the route and use a connected-space reference |
| Dialogue overlaps | Mouth movement and line order | Give speakers separate turns and a short pause |
| Dialogue is inaccurate | Words, pronunciation, and tone | Shorten the line and have a fluent reviewer check it |
| Edited color leaks | Hair, cuffs, edges, foreground crossings | Define the target surface and preserve neighboring regions |
| A replacement changes timing | Source and result side by side | Preserve source gestures, camera, cuts, and duration explicitly |
| Keyframes feel disconnected | Camera and object positions | Prepare more compatible images or simplify the connecting action |
| Background text becomes distracting | Signs, labels, packaging | Use plain surfaces or add exact typography in post-production |
| An intended loop jumps | Last and first poses, speed, lighting | Align both endpoint state and movement direction |
| Sound leads the action | Contact frame and sound onset | Name one audible event and its visible cause |

## Keep useful records

Save the prompt ID, your edited prompt, the selected model and mode, actual output settings, input roles, and a result link you may share. Note one success and one unresolved issue.

For editing, compare the output against the source. For reference generation, compare identity and shape against the reference. For keyframes, compare the important moments against the prepared images. Each workflow needs a different comparison.

## Share a reproducible contribution

Use the [contribution guide](../CONTRIBUTING.md) and submit the exact prompt rather than a description of what you intended to type. Label an untested recipe as a recipe. A tested contribution should include the result and the conditions used.
