## 세 단계로 시작하기

1. 글로 장면을 구상한다면 [텍스트로 영상 만들기](https://bestimage.ai/models/kuaishou/kling-4-0-text-to-video/)를, 시작 이미지가 있다면 [이미지로 영상 만들기](https://bestimage.ai/models/kuaishou/kling-4-0-image-to-video/)를 선택하세요. 각 항목의 입력 조건부터 확인합니다.
2. 프롬프트 전체를 복사한 뒤 피사체 수, 동작 순서, 마지막 상태를 유지하면서 수정하세요. 길이와 화면 비율은 제작 목표이며, 실제 설정은 이용하는 페이지의 선택 항목을 기준으로 합니다.
3. 확인 항목에 따라 영상을 다시 살펴보세요. 한 번에 한 가지 요소만 바꾸면 동작의 명확성이나 사물의 일관성에 영향을 준 요인을 비교하기 쉽습니다.

## 전체 예시: 돌려주는 우산

**방식:** 텍스트로 영상 생성  
**제작 목표:** 10초, 16:9  
**입력 자료:** 없음  
**목록 항목:** [K001](prompts/cinematic-stories.md#k001)

```text
비가 그친 뒤 작은 우산 수선점 안을 10초 동안 끊김 없는 미디엄 와이드 숏으로 보여준다. 짙은 초록색 앞치마를 입은 성인 점주가 나무 계산대 뒤에 서 있다. 접힌 노란 우산 한 개가 곡선형 손잡이를 오른쪽으로 향한 채 계산대 위에 가로로 놓여 있다. 처음 3초 동안 점주는 접어 놓은 파란 천을 우산 아래로 밀어 넣는다. 3초부터 7초까지 접힌 우산을 천천히 4분의 1바퀴 돌려 수선한 솔기가 손님 쪽을 향하게 한다. 마지막 3초 동안 양손을 거두고 화면 바로 밖에 있는 손님을 향해 부드럽게 미소 짓는다. 카메라는 반대편으로 넘어가지 않고 조금만 가까이 다가간다. 창문에서 들어오는 부드러운 빛이 바깥의 젖은 보도와 실내의 무광 노란 우산 천을 드러낸다. 소리는 바깥의 잔잔한 빗소리, 천이 나무를 스치는 소리, 손잡이가 가볍게 한 번 닿는 소리로 구성한다. 대사, 자막, 배경 음악은 없다. 우산은 계속 접힌 상태로 유지하고, 손잡이와 천의 색, 계산대 위 위치를 일관되게 유지한다.
```

**조정할 요소:** 우산 색, 앞치마 색, 창문 빛.

**확인할 사항:** 우산은 한 개이며 계속 접혀 있는가? 천은 우산 아래에 남아 있는가? 솔기가 우산 천과 함께 회전하는가? 마지막 정지 장면에 들어가기 전에 양손이 우산에서 떨어지는가?

먼저 동작을 유지하면서 색이나 빛을 바꿔 보세요. 카메라, 장소, 동작을 한꺼번에 바꾸면 결과가 달라진 원인을 파악하기 어렵습니다. 사물이 갑자기 늘어나거나 손이 우산 천을 통과하지 않는지, 소리가 화면의 동작과 맞는지도 확인하세요.
